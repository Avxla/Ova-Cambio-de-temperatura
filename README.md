
# OVA - Cambios de Temperatura

## Aprendiz

Andrés Ricardo Avila Barrera

## Tema

Cambios de temperatura

## Descripción

Este proyecto corresponde al desarrollo de un Objeto Virtual de Aprendizaje (OVA) sobre las escalas de temperatura Celsius, Fahrenheit y Kelvin.

## Tecnologías

- HTML5
- CSS3
- JavaScript
